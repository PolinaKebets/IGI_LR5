# ХимМаркет — Интернет-магазин бытовой химии

Django-проект для лабораторной работы №5 (Вариант 10) — интернет-магазин бытовой химии.

## Описание

Веб-приложение для продажи бытовой химии с полным циклом заказов: от просмотра каталога до получения заказа в пункте выдачи.

### Основные возможности

- **Каталог товаров** с категориями и производителями
- **Поиск товаров** по названию и описанию
- **Корзина заказов** — создание, редактирование, оформление
- **Пункты выдачи** — выбор удобного места получения
- **Календарь работы** пунктов выдачи
- **Личный кабинет** — история заказов, статусы
- **Панель сотрудника** — управление заказами
- **Статистика** — графики продаж, аналитика
- **Внешние API** — курсы валют, советы по безопасности

### Роли пользователей

- **Администратор** (admin/admin123) — полный доступ через Django Admin
- **Сотрудники** (emp1-3/password123) — управление заказами, статистика
- **Покупатели** (customer1-5/password123) — оформление заказов, история
- **Гости** — просмотр каталога, регистрация

## Технологии

- **Backend:** Django 4.2, Python 3.9
- **База данных:** SQLite (локально), PostgreSQL (продакшн)
- **Формы:** django-crispy-forms, crispy-bootstrap4
- **Изображения:** Pillow
- **Тесты:** pytest, pytest-cov
- **Деплой:** Docker, docker-compose, Render.com
- **Статика:** WhiteNoise

## Быстрый старт

### Требования

- Python 3.9+
- pip, virtualenv
- Docker (опционально)

### Локальная разработка

```bash
# Создание виртуального окружения
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Миграции
python manage.py migrate

# Создание демо-данных
python manage.py seed_data

# Запуск сервера
python manage.py runserver 8001
```

Доступ: http://127.0.0.1:8001/

### Docker

```bash
# Локальный запуск с PostgreSQL
docker-compose up --build

# Миграции в контейнере
docker-compose exec web python manage.py migrate
docker-compose exec web python manage.py seed_data
```

## Деплой на Render.com

1. Создать репозиторий на GitHub
2. Подключить в Render.com
3. Добавить переменные окружения:
   - `SECRET_KEY` — случайный секретный ключ
   - `DEBUG=False`
   - `DATABASE_URL` — PostgreSQL от Render
4. Автоматический деплой при push в main

## Модели данных

- **Product** — товар (название, цена, описание, производитель, категория)
- **Category** — категория товаров
- **Manufacturer** — производитель
- **Customer** — покупатель (ФИО, телефон, email, бонусы)
- **Order** — заказ (статус, сумма, дата, пункт выдачи)
- **OrderItem** — позиция заказа (товар, количество)
- **PickupPoint** — пункт выдачи (адрес, телефон, график)
- **Employee** — сотрудник (должность, смена)
- **PromoCode** — промокод (скидка, срок действия)
- **Review** — отзыв о товаре

## API endpoints

- `/api/currency/` — курс USD к RUB (внешний API)
- `/api/safety-tips/` — советы по безопасности товаров
